# GradeWise - Website Features & Architecture

GradeWise is an AI-powered steel grade selection platform tailored for Jindal Stainless. It features a modern, interactive Next.js (App Router) frontend utilizing React, Tailwind CSS, and Framer Motion, communicating with a Python/FastAPI backend. 

This document serves as a complete feature mapping and architectural guide to provide 100% context on how the application works, its user flows, and its simulation capabilities.

---

## 1. Core Search & Navigation

### 1.1 Natural Language Search Interface
- **Vanish Input Component:** The home screen features an Aceternity-style `PlaceholdersAndVanishInput` search bar that displays rotating starter prompts (e.g., "Need maximum pitting resistance for a marine structural load..."). Upon submission, the input field dissolves using a particle animation.
- **Dynamic Background Video:** The home page features a background video canvas. When the user initiates a search, the video instantly "freezes" (locks the frame) to focus the user's attention on the loading and result states.
- **Loading State:** Features a `MorphingSpinner` component overlaid on a solid black background with the text "FINDING THE BEST CHOICE", creating a premium transition feel.

### 1.2 State Persistence & Browser History
- The app handles navigation elegantly by utilizing the browser's History API (`pushState` / `popState`) and `sessionStorage`. 
- **Back Button Support:** If a user navigates to the detailed comparison or spec sheets and hits "Back," the application hydrates the previous search results seamlessly without requiring a re-fetch.
- **Out of Context Handling:** The frontend implements basic guardrails to detect unrelated queries (like "weather", "recipe", "capital") and throws a custom "Error: Out of Context" terminal-style UI state.

## 2. Recommendation Results UI

### 2.1 3D Expanding Accordion Cards
- The results are presented in a horizontal accordion layout utilizing Framer Motion. 
- **3D Perspective:** Hovering over or clicking a grade card triggers a 3D tilt effect (`rotateX`, `rotateY`) and expands the card to take up the majority of the flex container.
- **Visuals:** The cards pull corresponding steel grade images from `/grade images/[grade]/image.png`. It includes an automatic fallback array of images if the specific grade image is missing.
- **Data Display:** The expanded card displays the grade name, the alloy type, and a top toolbar.

### 2.2 Results Dashboard (Data Panel)
Below the accordion, the active (selected) steel grade displays detailed information:
- **AI Explanation & Trade-offs:** Detailed paragraphs generated by the AI explaining *why* this grade was chosen and what the specific trade-offs (e.g., "More expensive", "Harder to machine") are.
- **Quick Metrics:** Badges showing Yield Strength (MPa), Corrosion Resistance, and Weldability.
- **Refinement Chat:** A chat-like input bar allowing users to refine the current results (e.g., "Actually, I need it to be cheaper..."). This wraps the original context and previously recommended grades into a new prompt for the AI backend.

## 3. Interactive Physics & Environmental Simulators

The platform features custom-built, interactive physics simulators that re-calculate in real-time as users adjust sliders.

### 3.1 Bending Simulator (Bend Test)
- **Purpose:** Simulates placing weight on the center of a simply supported steel rod.
- **Inputs:** Rod Thickness (diameter in mm), Rod Length (mm), and Applied Weight (kg).
- **Calculations:** Uses realistic engineering formulas (Moment of Inertia, Section Modulus, Max Bending Moment) located in `physics.ts` to calculate the max deflection (mm), internal bending stress (MPa), and stress ratio against the steel's specific yield strength.
- **Visualization:** An SVG-based visualizer animates a bending curve using an SVG `<path>` and Quadratic Bezier curves. If the load exceeds the yield strength (stress ratio > 1.0), the rod turns red, displaying a "FAILED - Permanently Bent" state.

### 3.2 Tensile Simulator (Tensile Yield)
- **Purpose:** Simulates axial pull force on the steel.
- **Inputs:** Diameter, length, and load (shared state with the bending simulator for UI continuity).
- **Visualization:** Displays a visual horizontal progress bar representing the load percentage against the yield load capacity, outputting the elastic elongation stretch (mm) and applied force.

### 3.3 Corrosion Simulator
- **Purpose:** Simulates rust and surface pitting over time based on environmental exposure.
- **Inputs:** Liquid Environment toggle (Freshwater, Saltwater, Acidic), Fluid Temperature (0-100°C), and Exposure Time (1-50 Years).
- **Calculations:** Translates qualitative corrosion ratings (e.g., "Excellent", "Fair") into a base resistance score. It applies multipliers for acidity and heat to calculate "Accumulated Damage" and remaining "Surface Health".
- **Visualization:** Uses CSS radial gradients and absolute positioning to visually overlay rust (multiply blend mode) and pitting holes onto a clean steel texture based on the calculated surface health. 
- **States:** Transitions from "CLEAN" to "PITTING" (localized surface cavities) to "SEVERE RUST" (structural integrity lost).

### 3.4 Performance Matrix (Spider Chart)
- A radar/spider chart component mapping out the steel's specific performance across four main axes: Corrosion Resistance, Weldability, Yield Strength, and Max Service Temperature.

## 4. Deep Dive Pages

### 4.1 Comparison Tool (`/compare`)
- **Trigger:** A "Compare All Results" button on the results page.
- **Functionality:** Passes the full AI recommendation array via `sessionStorage` to a dedicated comparison page.
- **UI:** A side-by-side horizontal scroll matrix comparing all recommended grades against the "Primary Match" (the first recommendation). 
- **Relative Highlighting:** It calculates percentage differences (e.g., `+15% vs primary`) and conditionally colors them green or red depending on whether a higher value is better (e.g., Yield Strength) or worse (e.g., Cost Tier).
- **Compared Traits:** Yield Strength, Tensile Strength, PREN (Pitting Resistance Equivalent Number), Max Service Temp, Cost Tier, Weldability, and Machinability.

### 4.2 Grade Data Sheet (`/specs/[grade]`)
- **Functionality:** A dedicated URL for the full specification sheet of a specific grade, querying the local `gradeData.ts` database.
- **AI Context Restoration:** If the user navigated here from an AI recommendation, the page detects the context via `sessionStorage` and displays a highlighted "Recommendation Context" box explaining why it was recommended.
- **Data Sections:**
  - **Mechanical Properties:** Yield Strength, Tensile Strength, PREN.
  - **Chemical Composition:** A grid mapping chemical symbols to full element names (e.g., "cr" -> "Chromium") and displaying their percentage composition.
  - **Environmental & Fabrication Ratings:** Visual blocks for Cost Tier (1-5 rating visualizer), Max Service Temp, Weldability, and Machinability.

## 5. Technical Stack & Backend Integration

- **Frontend:** Next.js (App Router), React, Tailwind CSS.
- **Animation:** Framer Motion is used heavily for layout transitions, 3D transforms, presence animations, and physics SVG interpolations.
- **Data Source:** Static hardcoded data in `lib/gradeData.ts` representing the Jindal Stainless catalog. 
- **Backend API (`lib/api.ts`):** Expects a Python FastAPI backend running at `http://localhost:8000/recommend`. It sends the user query to the backend, which returns an array of recommended grades and contextual explanations.
- **Mock Fallback:** If the Python backend is unreachable, the API gracefully degrades to a `setTimeout` mock resolver that keyword-matches the prompt (e.g., "sea", "marine") and returns a hardcoded 316L/2205 recommendation payload to ensure the UI remains testable.
